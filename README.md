# SURAWITTAYAKARN STUDENT COUNCIL

เว็บไซต์ static สำหรับสภานักเรียนโรงเรียนสุรวิทยาคาร ออกแบบตามแนวทาง Bright Minds ด้วยโทนสีฟ้า รองรับภาษาไทย/อังกฤษ มือถือและคอมพิวเตอร์

## สิ่งที่มีในเว็บไซต์

- หน้าแนะนำสภานักเรียน แนวทางการทำงาน ทีมงาน และโครงการ
- ข่าวสารและแกลเลอรีพร้อมข้อความแจ้งเตือนเมื่อยังไม่มีเนื้อหา
- สลับภาษาไทย/อังกฤษ
- ภาพเคลื่อนไหวเล็กน้อยเมื่อเลื่อนหน้า พร้อมรองรับการตั้งค่าลดการเคลื่อนไหวของอุปกรณ์
- ข้อมูลตัวอย่างของโครงการอยู่ใน `app.js` และแสดงผลบนหน้าเว็บโดยตรง

เว็บไซต์นี้ไม่มีระบบหลังบ้าน ไม่มีฐานข้อมูล ไม่มีแบบฟอร์มส่งข้อมูล และไม่มีบัญชี Admin ข้อมูลในหน้าเว็บไม่ถูกส่งไปจัดเก็บที่อื่น

## เผยแพร่ด้วย GitHub Pages

1. เปิด Settings → Pages ใน repository
2. เลือก Deploy from a branch, branch ที่ต้องการเผยแพร่ และโฟลเดอร์ `/(root)`
3. บันทึกและเปิดลิงก์ GitHub Pages ของ repository

## แก้ไขเนื้อหา

แก้ข้อมูลคณะทำงานและโครงการตัวอย่างใน `app.js` แล้วบันทึกการเปลี่ยนแปลงบน branch ที่ตั้งค่าไว้สำหรับ GitHub Pages
